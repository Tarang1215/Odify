# 2026-10-28 위젯 재개·국가별 아티스트·화면 끔 재생 검증

작업 브랜치: `codex/company-debug-20261026`, 기존 draft PR #21. 준비 버전은 **preview12.69(81)**. 이전 최종 설치는 .68(80)이며 기존 OAuth 앱 ID와 영구 서명을 유지한다.

## 앱이 꺼진 뒤 위젯 재생

기존 위젯은 등록된 엔진이 없으면 재생 버튼에도 앱을 여는 PendingIntent를 넣었다. 프로세스가 종료되면 receiver가 저장된 곡을 복원하는 경로도 없었다.

- 재생 버튼에 명시적 receiver PendingIntent를 연결한다. 표시된 출처/곡 ID가 최근 저장 상태와 일치할 때만 cold resume을 허용한다. 다음/이전의 오래된 요청이 임의로 서비스를 되살리지는 않는다.
- YouTube: 기존 private 체크포인트의 곡·위치·대기열을 복원하고 사용자의 재생 클릭으로 foreground 서비스를 시작한다. Activity를 먼저 열 필요가 없다. 화면에 이미 복원돼 있지만 엔진이 없는 상태도 지원한다.
- Native/Drive/로컬: 별도 private 체크포인트에 대기열의 곡 순서(중복 occurrence 포함), 현재 index, 위치, 반복/셔플을 기록한다. 대기열 직렬화는 변경 때만, 위치는 이벤트 및 5초 간격으로 기록한다. 복원은 Media3 서비스가 정상 foreground 알림을 관리한다.
- 저장된 상태가 없거나 만료·불일치하면 임의의 곡을 재생하지 않고 안내한다. 초기 빈 위젯은 앱을 연다. 데이터 삭제, 권한 철회, 파일 삭제 후 재생을 보장하지 않는다.

## 별도 제공처의 국가별 아티스트 순위

사용자는 곡 차트를 집계한 자체 순위보다 별도 제공처의 국가별 아티스트 순위를 선택했다. [Last.fm geo.getTopArtists](https://www.last.fm/api/show/geo.getTopArtists)를 사용하며 한국·일본·미국 국가 선택과 연결한다. 이는 해당 나라에서의 Last.fm 청취 인기이며 아티스트 국적별 순위나 실시간 급상승 순위가 아니다.

- 제공처가 반환한 순서를 유지한다. 전 세계 listener 수 등을 재정렬해 국가 순위처럼 표현하지 않는다.
- 아티스트 사진은 기존 portrait 조회/캐시를 사용한다. 누르면 해당 가수의 곡 검색으로 이어져 저장소 밖 음악도 찾을 수 있다.
- 6시간 캐시와 저장 시각을 표시한다. 불러오기 실패와 미연결 상태를 구분하며 가짜 순위나 곡 차트 기반 대체 순위를 넣지 않는다.
- **실제 API 키는 아직 제공되지 않았다.** 프로필의 ‘국가별 인기 아티스트’에서 키를 입력하고 국가별 API 응답을 확인한 뒤 연결한다. 키는 Android Keystore AES-GCM으로 암호화하며 소스·문서·로그에 기록하지 않는다. 앱은 기존대로 backup 비허용이다. 실제 최신 순위 검증은 키 연결 후 해야 한다.

## 검증 및 남은 일

로컬 JVM 65개 + 생성된 플레이어 JS 9개 및 AndroidTest 컴파일을 통과했다. 새 안전 검사는 Native 복원 혼합 대기열, cold widget 표현, Last.fm 순서/오류/키 암호화를 포함한다. 실기기에서는 기존 안전 검사에 추가해 총 22개와 실제 무음 재생 4개를 실행하고, 프로세스를 종료한 뒤 실제 런처 위젯을 눌러 두 엔진의 재개를 별도로 확인한다. 완료 전 통과로 기록하지 않는다.

사용자가 요청한 장시간 검사는 최종 설치 후 음량 0, 화면을 끈 상태에서 **자연스러운 재생 60분**을 관찰한다. 곡을 끝으로 탐색하거나 다음 버튼을 자동으로 누르지 않고, Odify 세션의 진행·곡 전환·PID·화면 상태를 외부에서 기록한다. USB 연결/충전 중의 조건이므로 배터리 모드의 deep Doze 검증과 구분한다. 검사 중 음량이 0이 아니게 되거나 재생 중단/프로세스 변경을 발견하면 기록하고 Odify만 일시정지한다. 종료 시 원래 화면 유지 설정을 복구한다.
