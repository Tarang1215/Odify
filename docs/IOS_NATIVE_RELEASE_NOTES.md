빌드 19: 원본 음원 경로와 재생 요청, iPad 플레이어 전환을 수정합니다.
- APK의 음악 MASTER 연결을 iOS에도 적용합니다. 연결된 계정의 Odify 음악
  마스터 표를 읽고, 정확한 Drive 파일 ID 또는 ODF 코드를 통해 곡명·가수·
  앨범을 연결합니다. 파일명만 ODF로 남아 원본을 인식하지 못하던 경로를
  보완합니다. 설치 후 Drive의 ‘음악 보관함 다시 연결’을 한 번 실행하면
  음원과 MASTER 정보의 연결 결과를 확인할 수 있습니다. 표나 원본 음원은
  수정하지 않으며, 다른 계정·충돌 코드·사용자 수정값은 덮어쓰지 않습니다.
- localFile·Drive 파일 연결을 출처 분류값보다 우선해 오래된 YouTube 분류가
  있어도 원본을 네이티브로 재생합니다. 원본 연결이 빠진 Local·Drive 곡은
  오류로 안내하며 YouTube 검색으로 대체하지 않습니다. 태그가 없는 파일은
  파일명에 포함된 가수·곡명이 모두 맞을 때만 카탈로그 곡과 연결합니다.
- 웹 플레이어의 준비·정지 신호가 사용자의 재생 요청을 취소하지 않도록
  했으며, 준비 완료 시 곧바로 재생을 요청합니다. 명시적인 일시정지와
  서비스의 자동 재생 차단은 유지합니다.
- 전체 플레이어를 실제 전체 화면과 iPadOS 기본 확대 전환으로 바꿉니다.
  화면을 가로·세로로 따로 늘리던 전환을 제거하고 누른 위치에서 이어지게
  합니다. 배경은 화면 가장자리까지 채우고 버튼은 안전 영역 안에 둡니다.
- iPad 하단 바는 최대 1,000pt 폭으로 중앙에 두고, 재생 중에는 곡 정보와
  조작부가 두 유리 영역으로 분리되며 정지 시 다시 합쳐집니다. 음표 표시는
  유지하고 왼쪽 아래 Made for your music 문구는 제거합니다.
- 네이티브 음원에는 시스템 백그라운드 재생 정책을 명시합니다. 웹 음악에는
  공개 Audio Session API의 playback 유형을 선언하고, 앱 복귀 시 사용자가
  재생을 요청한 상태만 복원합니다. 백그라운드 정지를 20초 연결 오류로
  오인하지 않도록 했습니다.

중요: 무음 테스트 음원으로 검증한 네이티브 백그라운드 재생과 YouTube 웹

LiveContainer 환경에 영향을 받으며, 이번 버전에서 해결됐다고 판정하지
않았습니다. iPad에서 별도 확인이 필요합니다.

빌드 18: APK의 홈과 개인화 구성을 기준으로 추가 개선했습니다.

  재발견·오프라인 믹스를 만듭니다. 실제 30초 이상 재생한 시간만 기록하고
  60일·최대 1,000개의 기록을 기기에만 보관합니다. 기존 APK 기록 자동 이전은
  포함되지 않아 iOS에서 쌓인 기록부터 학습합니다.
- 미니플레이어는 Clear Liquid Glass와 앨범 색조·가는 반사 테두리를 사용하며,
  화면 위에 떠 있고 스크롤 끝의 여백을 확보합니다. 오른쪽 패널의 외곽 검정
  여백을 없애고, 미니플레이어·오른쪽 앨범·대기열에서 누른 위치를 시작점으로
  전체 플레이어가 확대되고 앨범 표지가 이어집니다.
- 아티스트 곡 목록은 중복 ID를 제거한 안정적인 목록으로 표시하고, 순위가
  아닌 번호를 제거했습니다. 재생 버튼은 46pt 원형·어두운 재생 아이콘입니다.
- Space 재생·일시정지, 좌우 5초 이동, Shift+좌우 15초 이동, ⌘+좌우 곡 전환,
  위아래 앱 음량, Esc 접기, ⌘F 검색과 ⌘1–4 화면 전환을 지원합니다.
  글을 입력하거나 다른 대화상자를 열면 입력칸의 키보드 동작을 우선합니다.
- 아래 빌드 17의 가사 검색·Drive 우선·자동 재생·미국 차트 수정도 포함합니다.

시뮬레이터의 터치·키보드·스크롤 검사와 화면 캡처를 함께 남깁니다.
실제 키보드·iPad 터치감·장시간 잠금 재생은 기기에서 확인이 필요합니다.

빌드 16: YouTube 연결 오류 -2의 검색 결과 처리 문제를 수정합니다.
iPad의 모바일 검색 결과(videoWithContextRenderer)와 문자열로 전달되는
검색 데이터를 읽지 못해 결과가 있어도 0개로 처리하던 문제였습니다.
모바일·데스크톱·새 카드 형식을 지원하고, 검색 데이터가 늦게 준비되면
짧게 기다립니다. 가수·곡명 + official audio에서 정확한 결과가 없으면
APK와 같은 lyrics 검색도 확인합니다. 가사 본문 유무는 재생 조건이 아닙니다.
다른 가수·커버·라이브 영상을 자동 선택하지 않으며, 일치 결과 없음(-2),
검색 형식 오류(-3), 사용자 확인 필요(-4)를 구분합니다.
기존 Drive 스트리밍과 네이티브 음악 화면을 유지합니다.
실제 공개 iPad 검색 응답으로 형식 문제를 재현했으며, 자동 검사는
물리적인 iPad의 실제 YouTube 재생·화면 꺼짐 검사를 대신하지 않습니다.

빌드 15: 현재 Android APK의 음악 앱 경험을 iOS 이식 기준으로 삼습니다.
기존 앨범 표지·재생바·버튼·Liquid Glass 화면을 유지하고, YouTube는
앱 내부 WKWebView / IFrame 재생 엔진으로 전환했습니다. iOS의 기본
YouTube 재생은 직접 오디오 주소를 추출하지 않습니다. 알려진 영상 ID는
바로 재생하고, 카탈로그 곡은 공개 검색 결과에서 아티스트·제목이 맞는
영상을 연결합니다. 검색에 사용자 확인이 필요하거나 영상이 제한되면
오류를 표시합니다. 자동 재생 허용이나 서비스 접근을 보장하지 않습니다.
음악 화면의 재생·일시정지·탐색·대기열 재정렬과 Web/Local/Drive 전환을
같은 제어 계층에 연결했습니다. 곡 전환에는 같은 웹 플레이어를 재사용합니다.
화면 꺼짐·장시간 재생·시스템 조작의 Android 동등성은 실제 iPad에서
검증해야 합니다. 사설 API, 페이지 가시성 위조나 무음 유지음은 사용하지 않습니다.
아래 빌드 14까지의 직접 오디오 수신 설명은 이전 실험 경로에 해당합니다.

빌드 14: YouTube 음원 구간 요청이 401/403/429로 거절되면 해당 소스의 추가

사용합니다. 실제 iPad에서의 시간 초과 해결 여부는 별도 확인이 필요합니다.
