Odify MASTER 전체 수집

실행: run_master_all.bat를 더블클릭합니다.
이전 run_first_2026.bat도 이제 같은 MASTER 전체 수집을 실행합니다.

1. 매번 최신 Google MASTER 시트를 읽습니다. CSV를 직접 내보낼 필요가 없습니다.
2. Drive 실제 파일과 시트의 Drive 파일 링크를 확인해 이미 있는 곡은 건너뜁니다.
3. 누락곡을 MP3로 내려받고 커버·가사 보완을 시도합니다.
4. 링크가 없는 곡은 검색 후 가수·곡명·공식 오디오·버전을 검증합니다.
5. 모호한 곡은 임의로 다른 곡을 받지 않고 재검토로 남깁니다.
6. 곡마다 Drive에 올리고 원격 파일 일치 검사를 통과해야 완료로 기록합니다.

152곡 제한과 연도 제한은 없습니다. MASTER에 추가된 곡도 다음 실행에 포함됩니다.
시트 원본은 수정하지 않습니다. PC와 인터넷 연결을 유지하세요.
중단 후 같은 파일을 다시 실행하면 이미 있는 곡은 다시 받지 않습니다.
이미 전체 수집이 실행 중일 때 중복 실행하면 새 작업은 시작하지 않습니다.

결과 위치: 사용자 Music/Odify_Library/MASTER
- master_status.csv: 모든 곡의 수집·재검토·실패 상태
- master_report.json: 전체 진행 수와 상세 결과
- Audio: 내려받은 음악
- Lyrics: 가사

새 PC에서만 install_and_connect.cmd로 최초 연결하세요.
기존 Google 승인을 재사용하며 결제·유료 체험은 등록하지 않습니다.
Python 실제 실행 파일과 -m yt_dlp를 사용하므로 기존 PATH 오류를 피합니다.
Google/YouTube가 접근을 차단하면 상태를 남기고 중단합니다. 차단 우회는 하지 않습니다.

연결을 취소했거나 Google이 재인증을 요구할 때만 다시 승인해야 합니다.
인증 정보는 Windows 개인 폴더에 저장하며 ZIP과 GitHub에 포함하지 않습니다.
