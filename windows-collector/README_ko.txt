Odify 개인 음악 수집 자동 설정

이미 이 PC에서 연결을 완료했다면 run_first_2026.bat만 더블클릭하세요.
기존 Google 승인을 재사용하며 rclone 설정 질문에 다시 답할 필요가 없습니다.
실행 중에는 PC와 인터넷 연결을 유지하세요. 중단 후 같은 파일로 재개합니다.

새 PC에서 처음 사용할 때
1. Google Cloud의 개인 Desktop OAuth JSON을 한 번 다운로드합니다.
2. install_and_connect.cmd를 더블클릭합니다.
3. Google 로그인 및 개인 앱 권한 승인만 완료합니다.
4. run_first_2026.bat로 수집을 시작합니다.

결제 계정과 유료 체험은 필요하지 않습니다. 설치기는 과금을 활성화하지 않습니다.
필요한 프로그램이 설치돼 있으면 재설치하지 않습니다.
인증 정보는 Windows 개인 폴더에 보관하며 ZIP과 GitHub에 포함하지 않습니다.

수집 대상은 포함된 2026년 152곡 목록입니다. 검증된 링크는 151곡이며,
재검토가 필요한 링크 1개는 자동 처리하지 않습니다.
기존 업로드 폴더의 곡은 확인 후 건너뛰며 결과는 Music/Odify_Library/2026에 저장됩니다.
기존 Odify_Music_Test 폴더와 새 업로드 대상 Odify_Auto_Upload는 별도 폴더입니다.

연결을 취소하거나 Google이 재인증을 요구하는 경우에만 다시 연결해야 합니다.
인터넷 오류만으로 저장된 인증을 덮어쓰지 않습니다.
YouTube 접근 오류나 곡별 추출 실패는 Google Drive 연결 성공과 별개입니다.
